# WeatherAI 🌤

Telegram-бот для получения текущей погоды по названию города с **ежедневными уведомлениями**.

---

## Установка (uv)

```bash
cd ~/Desktop/WeatherAI

# Создать uv-окружение и установить зависимости
uv sync

# Активировать окружение
source .venv/bin/activate
```

Или запускать без активации через `uv run`:
```bash
uv run python weather.py "Москва"
uv run python bot.py
```

---

## Настройка

### 1. OpenWeatherMap API ключ
1. Зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/api) (бесплатно)
2. После подтверждения email получите API ключ в разделе "API keys"
3. Укажите его в файле `.env`:
   ```
   OPENWEATHER_API_KEY="ваш_ключ_здесь"
   ```

### 2. Telegram Bot Token
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученный токен и укажите в `.env`:
   ```
   TELEGRAM_BOT_TOKEN="ваш_токен_здесь"
   ```

## Запуск

### Консольный режим (как раньше)
```bash
uv run python weather.py
# или с городом сразу:
uv run python weather.py "Москва"
```

### Telegram-бот
```bash
uv run python bot.py
```
Бот будет работать, пока не нажмёте `Ctrl+C`. Для постоянной работы на сервере используйте `systemd`, `supervisor` или `docker`.

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и справка |
| `/weather [город]` | Погода по городу (если город не указан — используется город по умолчанию) |
| `/default <город>` | Установить город по умолчанию для уведомлений |
| `/notify HH:MM` | Включить ежедневные уведомления в указанное время (например, `/notify 7:00`) |
| `/notify` | Показать текущие настройки уведомлений |
| `/daily_off` | Выключить ежедневные уведомления |
| `/daily_status` | Показать статус уведомлений |

### Примеры:

```
/weather Москва
/default Санкт-Петербург
/notify 7:00
/notify 08:30
/daily_status
/daily_off
```

## Ежедневные уведомления

1. Установите город по умолчанию: `/default Москва`
2. Включите уведомления: `/notify 7:00` — бот будет каждый день в 7:00 присылать погоду
3. Проверьте статус: `/daily_status`
4. Отключите при необходимости: `/daily_off`

> ⚠️ Бот должен быть запущен (`uv run python bot.py`), чтобы уведомления приходили. Для автозапуска настройте systemd-сервис или запустите в `screen`/`tmux`.

